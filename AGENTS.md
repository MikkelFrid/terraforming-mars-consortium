# AGENTS.md

## Cursor Cloud specific instructions

### Artwork

Never create, redraw, or reconstruct binary art assets by hand. All Consortium
artwork is generated by `tools/consortium-art/build_assets.py` (Pillow). If
artwork looks wrong, change the generator — never hand-edit or approximate an
image from screenshots or descriptions.

```bash
python3 tools/consortium-art/build_assets.py
```

Standard commands for this repo (lint, test, build, dev) are documented in
`CLAUDE.md` and `.cursor/rules/consortium.mdc`.
