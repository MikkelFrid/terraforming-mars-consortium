# AGENTS.md

## Cursor Cloud specific instructions

### Artwork

Never create, redraw, or reconstruct binary art assets (icons, tiles, board
hexes, tag PNGs, expansion icons, etc.). Real artwork is authored outside the
agent session and arrives via git commits (for example `art/consortium-icons`).

If expected art files or an art branch are missing, **stop and ask**. Do not
approximate from screenshots or descriptions.

Standard commands for this repo (lint, test, build, dev) are documented in
`CLAUDE.md` and `.cursor/rules/consortium.mdc`.
