### How this codebase counts tags on event cards

Default tag counting **does not** include tags on event cards:

1. `PlayedCards.pushCard` stores event tags in `_eventTags`, not `_tags`
2. `Tags.rawCount(tag, includeEventsTags)` only adds `_eventTags` when
   `includeEventsTags` is true
3. `Tags.count` / `multipleCount` set `includeEvents` only for
   `raw-underworld` mode or when the player has **Odyssey** in tableau

So under normal rules (no Odyssey), an event’s Prospecting tag would **not**
count toward Iridium Cartel VP or a “Requires N Prospecting tags” check after
play. That is why Salvage Claim and Assay Rights are automated.
