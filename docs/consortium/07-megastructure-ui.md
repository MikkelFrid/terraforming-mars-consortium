## Pattern choice

**Pathfinders planetary tracks**, not Turmoil’s party board.

Pathfinders already renders named progress rows with an emblem and discrete
cells — the same job as five megastructure segment tracks. Turmoil’s party
panel is a dense board of delegates and agendas; it does not map cleanly onto
segment ownership.

Collapse chrome follows **Milestones / Awards** (`ma-title` +
`PreferencesManager`), defaulting to **collapsed**
(`show_megastructure_details: false`) the way Turmoil’s Policies subsection
defaults hidden via `getVisibilityState`. Five expanded tracks would compete
with the 891×860 Consortium board; collapsed-by-default keeps the page usable.

## What the panel shows

For each of the five structures in play:

| Element | Source |
|---------|--------|
| Name + emblem | `displayName` + `assets/consortium/megastructures/<id>.png` |
| Segment track | Filled cells use `board-cube--{color}`; keystone is larger with gold rim |
| Next cost | `nextSegmentCost` (+ keystone min-iridium callout) |
| Eligibility | `canContribute` or `ineligibility`: `cannot_afford` / `missing_foundation` |

Completed structures show a Complete badge, per-player segment counts (keystone
marked), and stub completion text until phase 6c.

## Contributing

`Player.getActions` still exposes `Megastructures.contributeAction` (OrOptions).
Panel **Contribute** buttons submit the matching nested `or` response via
`buildContributeResponse` — one click to the payment dialog when the action is
available, same cost as selecting the option in the Actions menu.

Payment:

- `SelectPayment.vue` includes **iridium** in the spend order (was missing)
- `SelectPaymentDeferred` / `SelectPayment` / `PaymentForm` honour `minIridium`
  with the message `Keystone requires at least N iridium` (no silent reject)

## Screen space

At 1920×1080 with `consortium_board_scale` 0.85 the board paints ~757×731.
The panel sits under the board (Pathfinders placement) and defaults collapsed.
Expanded, five compact rows (~720px wide) remain reachable by scroll; the board
was **not** shrunk further. If a denser simultaneous layout is required later,
say so — do not reduce board scale below 0.85 for this panel.
